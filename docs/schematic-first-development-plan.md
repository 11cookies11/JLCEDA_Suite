# 原理图优先开发清单

目标是先把原理图质量做稳，再把 PCB 自动化和 JLCEDA 原生能力串起来。优先级按“可用、稳定、可迭代”排序。

## 第一阶段：先保证能用

- 原理图器件放置正确
- 原理图导线真正连到 pin
- 参考标号、器件名称不压线
- 电源块基本结构清楚
- 原理图可保存、可导入、可检查

## 第二阶段：保证交给 JLCEDA 后能顺滑转 PCB

- 原理图功能块分区清楚
- 去耦、电源入口、接口器件位置合理
- 悬空 pin、断线、重叠、拥挤点尽量在原理图阶段消掉
- 尽量复用 JLCEDA 原生的原理图转 PCB、自动布局、自动布线能力

## 第三阶段：做可持续改良的工程习惯

- 规则参数化，不把所有偏好写死
- profile 可切换，支持不同项目风格
- 保留人工修正结果，逐步优化默认策略
- 只把高频、稳定、收益高的规则固化进代码

## 建议的职责划分

- Codex：高层决策和任务拆解
- Server：规则计算、编排、建议生成
- Plugin：JLCEDA 里的真实执行
- JLCEDA 原生能力：优先复用

## 暂缓项

- 复杂 PCB 侧自动优化
- 低频的特例规则
- 不影响原理图转 PCB 的高级美化
- 重复造 JLCEDA 已经提供的能力

## 这版开发目标

先做出一个 AI agent 可以持续研发、可直接使用的开发版原理图工作流，再逐步把经验收敛成配置和规则集。
