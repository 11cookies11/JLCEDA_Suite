# STM32 Minimal System Demo

This project is a smoke example for the refactored package layout using a
fresh STM32F103 minimum system board model.
It uses the current project structure:

- `source/circuit-model.source.json` is the editable source model.
- `build/ir.v1.json` is generated by `agent build-ir`.
- `build/ir-validation.json` is generated by `agent validate-ir`.
- `build/report.json` and `build/report.md` are generated by `agent report`.

Try it from the repository root:

```powershell
$env:PYTHONPATH = "src"
python -m kicad_suite.cli agent status --project examples/refactor-layout-demo
python -m kicad_suite.cli agent inspect --project examples/refactor-layout-demo
python -m kicad_suite.cli agent resolve-symbols --project examples/refactor-layout-demo --timeout 120
python -m kicad_suite.cli agent build-ir --project examples/refactor-layout-demo
python -m kicad_suite.cli agent validate-ir --project examples/refactor-layout-demo
python -m kicad_suite.cli agent export-kicad --project examples/refactor-layout-demo
python -m kicad_suite.cli agent report --project examples/refactor-layout-demo --markdown
```

The board includes the minimum-system blocks:

- STM32F103C8T6 in LQFP-48
- AMS1117-3.3 regulator with input/output capacitors
- 8 MHz HSE crystal and load capacitors
- BOOT0 pull-down and NRST pull-up/reset button
- SWD header
- 5 V power input header and power LED

The model is intentionally compact and built from scratch for this demo, but it
still exercises the new
`entrypoints`, `application_services`, `domain/core`, `orchestration`, and
`adapters` imports.

Generated KiCad output is written to
`output/refactor_layout_demo/refactor_layout_demo.kicad_pro`.
The current generated PCB contains all 17 footprints. ERC still reports pin type
findings from generated/JLC symbols, so treat ERC as an inspection report rather
than a fabrication gate until symbol pin-type normalization is improved.
