# 14 DDR 收口方案

Status: Draft

## 目标

把 H618 AgentBoard V1 的 LPDDR4 方案收口到“可进入正式布局约束”的状态。

## 当前原则

- V1 只保留一套成熟参考设计导向的 LPDDR4 方案。
- DDR 拓扑不允许再被当作普通外设网络处理。
- 只要 DDR 仍然悬空，原理图和 PCB 都不能被视为最终版。

## 关键约束

1. DDR 是单独的约束域
- 所有 DDR 数据、地址、控制、时钟和电源相关网络必须视为一个整体。
- 任何局部修改都要检查是否破坏整体拓扑。

2. 参考设计优先
- 所有最终连线优先参考成熟的 H618/H616 板级方案。
- 未经参考设计确认的引脚归属不得直接冻结。

3. 电源和去耦要一并定版
- `+1V2_DDR` 和 `+0V9_DDR` 必须和拓扑一起确认。
- DDR 去耦、参考电压和回流路径都要在同一份约束里说明。

4. 布局先于布线
- 先锁定 SoC 与 DDR 的相对位置。
- 再锁定走线方向、过孔策略和关键长度控制。

## 需要补齐的信息

- LPDDR4 颗粒的最终封装和位宽
- 数据、地址、控制脚的最终分配
- 参考电压和终端策略
- 电源去耦和局部供电路径
- 与 H618 引脚的最终对应关系

## 布线原则

- DDR 网络不与低速外设共享解释空间。
- 不在模型未冻结前提前定义最终走线。
- 任何通道长度、层切换和阻抗策略都应服务于参考设计目标。

## 与模型的关系

- `circuit-model.json` 中的 `U3` 备注应指向本文件的约束。
- 后续原理图分图应把 DDR 作为独立模块处理。
- PCB 阶段必须先满足 DDR，再谈接口密度和外形紧凑度。
