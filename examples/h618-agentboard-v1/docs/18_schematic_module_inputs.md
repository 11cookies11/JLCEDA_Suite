# 18 原理图模块输入

Status: Draft

## 目的

把前面的收口结论翻成原理图分图时可以直接使用的模块输入说明。

## 使用方式

- 每个分图只负责一类功能。
- 每个分图都要有明确的输入、输出和冻结约束。
- 分图之间只通过已经命名好的网络连接，不靠隐含理解。

## `sheet_00_top` 总图

### 放置内容

- 项目入口与全局网络说明
- 跨模块连接提示
- 仅保留不属于任何单一模块的标记类内容

### 输入

- `+5V_IN`
- 全局地
- 关键跨模块网络名

### 输出

- 指向各功能分图的引用

### 冻结约束

- 不放具体功能器件。
- 不放会干扰分图职责的局部连接。

## `sheet_01_power_entry_pmic`

### 放置内容

- `J1` USB-C 5V 输入
- `F1` 输入保险
- `D1` 输入保护
- `U1` PMIC
- 与电源和复位相关的去耦、上拉和测试点

### 输入

- `+5V_IN`
- 地
- PMIC 控制脚

### 输出

- `+5V_SYS`
- `+3V3`
- `+1V8`
- `+1V1_CORE`
- `+1V2_DDR`
- `+0V9_DDR`
- `H618_PMIC_I2C_SCL`
- `H618_PMIC_I2C_SDA`
- `H618_PMIC_INT`
- `H618_PMIC_PWRON`

### 必须满足

- 上电顺序和复位联动必须与 [PMIC 收口方案](13_pmic_closure.md) 一致。
- 所有主电源都必须有可测量测试点。
- 电源入口不得污染启动链。

## `sheet_02_soc_boot_clock`

### 放置内容

- `U2` H618 SoC
- `Y1` 24MHz 晶振
- `Y2` 32kHz 晶振
- 启动相关电阻电容

### 输入

- `+1V1_CORE`
- `+3V3`
- `H618_RESET_N`
- `H618_FEL_BOOT`
- `H618_PMIC_I2C_SCL`
- `H618_PMIC_I2C_SDA`

### 输出

- `H618_UART0_TX`
- `H618_UART0_RX`
- `H618_RESET_N`
- `H618_FEL_BOOT`
- `H618_24M_OSC`
- `H618_32K_OSC`

### 必须满足

- SoC pinmap 必须与 [SoC pinmap 收口方案](15_soc_pinmap_closure.md) 一致。
- 调试串口必须最早可用。
- 时钟和启动脚不能依赖未冻结的扩展功能。

## `sheet_03_memory_ddr`

### 放置内容

- `U3` LPDDR4
- DDR 去耦、电源与参考网络

### 输入

- `+1V2_DDR`
- `+0V9_DDR`
- `H618_LPDDR4` 相关信号

### 输出

- DDR 数据、地址、控制和时钟相关网络

### 必须满足

- DDR 拓扑必须与 [DDR 收口方案](14_ddr_closure.md) 一致。
- DDR 视为单独约束域。
- 布线前不得再推翻参考设计。

## `sheet_04_boot_storage`

### 放置内容

- `J2` MicroSD
- `U4` SPI NOR

### 输入

- `H618_SDIO`
- `H618_SPI_NOR`
- `H618_FEL_BOOT`

### 输出

- 主启动路径
- 备用启动路径
- 恢复路径

### 必须满足

- MicroSD 是首选启动介质。
- SPI NOR 保留恢复和备用启动职责。
- FEL 必须能在两条存储路径失败时接管。

## `sheet_05_debug_and_control`

### 放置内容

- `J3` UART0 调试口
- `SW1` RESET
- `SW2` FEL / BOOT
- `TP5` 到 `TP8`

### 输入

- `H618_UART0_TX`
- `H618_UART0_RX`
- `H618_RESET_N`
- `H618_FEL_BOOT`

### 输出

- 串口日志
- 手动复位
- 手动恢复入口

### 必须满足

- 调试口必须在板边且可探测。
- `RESET` 和 `FEL` 不能被高大器件遮挡。
- 该分图不得依赖复杂外设才能工作。

## `sheet_06_network`

### 放置内容

- `U5` RTL8211F
- `J6` RJ45 with magnetics

### 输入

- `H618_RGMII`
- `H618_RGMII_MDC_MDIO`
- `H618_RGMII_RESET`

### 输出

- 千兆以太网连接

### 必须满足

- 参考设计、磁性器件和 PHY 复位要一致。
- RGMII 不能破坏 boot-critical 路径。
- 走线和回流路径要按高速接口约束处理。

## `sheet_07_usb`

### 放置内容

- `U6` USB2514B
- `J7`、`J8` USB-A Host 端口

### 输入

- `H618_USB0`
- `USB_HUB_RESET`
- `+5V_SYS`
- `+3V3`

### 输出

- 两个 USB Host 下游端口

### 必须满足

- USB Hub 是 V1 的外设扩展域。
- Hub 复位和端口供电必须可控。
- 端口布置必须支持测试和返修。

## `sheet_08_display`

### 放置内容

- `J9` HDMI 连接器

### 输入

- `H618_HDMI`
- `+3V3` 或相关显示电源

### 输出

- 显示输出

### 必须满足

- HDMI 连接器、ESD 和电源关系要一起冻结。
- 显示输出不能干扰启动链。

## `sheet_09_expansion`

### 放置内容

- `J4` 26Pin 扩展口
- `J5` 预留协处理器口

### 输入

- `H618_26PIN_*`
- `H618_COPRO_UART`
- `+3V3`
- `+5V_SYS`

### 输出

- GPIO、UART、I2C、SPI 与未来扩展能力

### 必须满足

- 26Pin 映射必须与 pinmux 草案和 DTS 可追溯。
- 预留协处理器口不得反过来影响 V1 启动。

## `sheet_10_testpoints_led`

### 放置内容

- `TP1` 到 `TP4`
- `LED1`
- `R4`

### 输入

- 主电源测试点
- 关键调试和恢复信号

### 输出

- 可测量性
- 基础上电指示

### 必须满足

- 测试点必须优先覆盖电源、调试和恢复链。
- 指示灯不能影响关键信号。

## 模块间固定关系

- PMIC 先于所有其他模块建立基础电源。
- 启动存储和 DDR 共同决定最小可启动系统。
- 调试模块必须在不依赖复杂外设时独立可用。
- 外设接口不得反过来污染启动链。

## 后续使用原则

- 真正画原理图时，先从 `sheet_01`、`sheet_02`、`sheet_03`、`sheet_04` 开始。
- 每个分图只要遵守本文件的输入输出边界，就可以继续向 KiCad schematic 落地。
- 如果某个器件或网络会打破这里的职责边界，先回到收口文档修改，不要直接在原理图里硬接。
