# H618 AgentBoard V1 采购可下单清单

这份文档只回答一个问题：当前这版原理图里，哪些东西已经可以按 BOM 直接下单，哪些东西仍然只是后续复核项。

## 已落实的采购项

- `F1` USB 输入保险丝
- `D1` USB VBUS TVS
- `SW1` RESET 按键
- `SW2` FEL / BOOT 按键
- `C1 / C2` 24MHz 晶振负载电容
- `C3 / C4` 32kHz 晶振负载电容
- `C5 / C6 / C7` PMIC 与电源域 22uF 去耦
- `C8` 核心电源域 47uF 去耦
- `TP1` 到 `TP10` 测试点作为 PCB 功能件保留

## 仍需复核的核心项

- `U2` 最终器件级 pinmap
- `U3` 完整 LPDDR4 参考拓扑
- `U1` 最终 PMIC 电源树和时序
- `RGMII / USB Hub / HDMI / USB-C` 的最终器件级细节

## 结论

- 当前这版已经具备直接按 BOM 下单的条件。
- 它仍然不是“可直接量产定版”的最终版。
- 如果目标是打样，接下来优先看的是 `U2 / U3 / U1` 三个核心复核项，而不是再去动已经落实的通用 BOM。
