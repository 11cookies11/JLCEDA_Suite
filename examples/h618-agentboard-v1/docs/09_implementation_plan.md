# 09 实施计划

Status: Draft

实施目标：

- 先收口需求，再收敛接口
- 先锁电源和启动链，再锁 DDR
- 先完成可调试、可恢复的第一版，再追求接口完整度

推荐顺序：

1. 需求收口
2. 接口与 pinmux 收敛
3. 电源树与启动链定版
4. 原理图模块化
5. PCB 规划与布局
6. 布线与 DRC 收尾
7. Bring-up 与返修闭环

阶段输出物：

- 需求收口版
- 参考引脚表
- 电源树说明
- 原理图模块拆分
- PCB 约束清单
- Bring-up 检查单

当前建议优先级：

- `UART0`
- `RESET`
- `FEL / BOOT`
- `MicroSD`
- `SPI NOR`
- `电源树`
- `DDR 参考拓扑`
- `网口`
- `USB Host`
- `GPIO 扩展`

备注：

- 所有未确认的引脚映射都应保留 `NEED_VERIFY`
- DDR 和 PMIC 相关内容不要在没有参考设计的情况下自由发挥
- 第一版目标是能稳定点亮和恢复，不是一次性做满所有功能
