# 10 拓扑完整度清单

Status: Draft

目的：

- 判断当前 H618 AgentBoard V1 的电路拓扑是否已经足够支撑正式原理图和 PCB
- 把“已经完成”“必须补”“可延期”“可不做”分开
- 让需求、架构、pinmux、启动链和 PCB 约束对同一套结论保持一致

判定标准：

- **系统骨架完整**：模块齐全，主功能链路明确
- **电气拓扑完整**：关键器件级连接可直接落到原理图
- **工程拓扑完整**：可以开始稳定画图、布板和验证

当前结论：

- 系统骨架：基本完整
- 模块拓扑：基本完整
- 电气拓扑：未完全定版
- 工程拓扑：尚未到最终完整状态

已完成：

- `5V` 输入、保护、PMIC、主 SoC、DDR、启动存储、网口、USB、调试口、扩展口、测试点的高层模块已经建立
- `UART0 / RESET / FEL / MicroSD / SPI NOR` 的优先级已明确
- 需求、架构、电源树、启动链、pinmux、模块拆分、PCB 约束和 bring-up 计划已经成文

必须补：

- `U2 H618` 的最终器件级 pinmap
- `U3 LPDDR4` 的完整参考拓扑
- `U1 PMIC` 的最终电源树和时序
- `MicroSD / SPI NOR / FEL` 的最终恢复闭环
- `RGMII / USB / HDMI` 的最终器件级连接

可延期：

- `J5` 协处理器预留口的最终用途
- `HDMI` 的最终可用程度
- `J4` 上部分复用脚的软件侧最终分配
- 额外扩展 I2C / SPI 的最终细分

可不做：

- 第二套复杂协处理器控制逻辑
- 非关键高速扩展口
- 不影响 V1 启动和调试的附加人机功能

当前建议：

- 先补 `PMIC`、`DDR` 和 `启动存储`
- 再把 `SoC pinmap`、`网络` 和 `USB` 器件级细节收紧
- 最后决定是否把 `HDMI` 和协处理器预留口提升到 V1 必做项

结论：

- 这份拓扑已经足以继续推进原理图和 PCB 设计
- 但还不能宣称“最终电气拓扑完整”
