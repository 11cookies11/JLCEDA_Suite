# 06 PCB 约束

Status: Draft

目标：

- 优先保证可布线、可调试、可返修
- 先围绕电源、DDR 和高速接口建立布局约束
- 不在第一版为了紧凑牺牲可制造性

布局优先级：

1. `U2` SoC
2. `U1` PMIC
3. `U3` LPDDR4
4. `U5` 以太网 PHY
5. `U6` USB Hub
6. `U4` SPI NOR
7. `J2` MicroSD
8. `J3` 调试口
9. `J1` 电源入口
10. `J4` 扩展口

板框和机械约束：

- 接口尽量放在板边，保证插拔和测量方便
- `J3`、`TP5`、`TP6`、`TP7`、`TP8` 必须能从板外直接接触
- `U2`、`U3`、`U1` 的布局要为短走线和连续参考平面服务
- 高速接口周围要预留返修空间

DDR 约束：

- DDR 走线参考设计优先级最高
- `U3` 必须靠近 `U2`
- 电源、地和参考平面不能被其他模块切断
- 去耦电容必须贴近 DDR 供电脚

电源约束：

- `J1` 到 `F1 / D1 / U1` 的路径要短而明确
- 大电流电源回路要最小化
- `TP1` 到 `TP4` 必须便于测量
- 关键电源域应避免跨越分割地

高速信号约束：

- `RGMII`、`USB`、`HDMI`、`DDR` 需要优先布线
- 差分对保持连续参考平面
- 尽量减少不必要过孔
- 敏感信号不要靠近开关电源噪声源

调试和服务性约束：

- `J3` 和按键必须在样机阶段易于操作
- `FEL / BOOT` 和 `RESET` 不得被高器件遮挡
- 关键测试点优先放在边缘或可探测区域
- 第一版应留出返修和飞线空间

布局建议：

- 先固定 `U2 / U3 / U1` 的相对位置
- 再放 `U5 / U6 / U4 / J2`
- 最后补 `J3 / J4 / J5 / J6 / J7 / J8 / J9` 和测试点

布线优先级：

1. 电源
2. DDR
3. 时钟
4. RGMII
5. USB
6. 启动存储
7. 调试与扩展

DRC 收敛标准：

- 关键信号不允许出现未解释的悬空连接
- 电源与地网络必须与原理图命名一致
- DDR、RGMII、USB 和 HDMI 走线不得破坏连续参考平面
- 测试点和调试口不得因为布局而失去可探测性
- 第一版允许已知占位符，但必须明确标注并可追踪

收敛顺序：

1. 修正板框与接口位置
2. 修正电源和地回流路径
3. 修正 DDR 和时钟
4. 修正 RGMII / USB / HDMI
5. 修正调试与测试点
6. 最后处理剩余 ERC / DRC 提示

待确认项：

- 最终板框尺寸
- 接口在四周的分布方式
- DDR 走线层叠和阻抗目标
- 是否需要预留散热片或屏蔽罩空间
