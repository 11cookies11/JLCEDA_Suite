# 17 接口收口方案

Status: Draft

## 目标

把 `RGMII / USB / HDMI` 三个外部接口域从“功能存在”收口到“可以进入正式布局实现”的状态。

## 与阶段 4 的关系

- 本文是阶段 4 的接口收口说明。
- 具体资料采集和扩展顺序以 [高速接口参考设计采集清单](15_high_speed_reference_capture_checklist.md) 为准。
- 在清单完成前，这三个接口仍应保持“证据优先、参考捕获”的状态，不应被当成完全定版拓扑。

## 当前结论

- `RGMII` 是以太网接口域，核心关注点是 PHY、磁性器件和时序。
- `USB` 是外设扩展域，核心关注点是 Hub、下游端口和复位/供电控制。
- `HDMI` 是显示输出域，核心关注点是连接器、ESD 和电源/屏蔽细节。
- 这三块都不是 boot-critical，但都必须在 V1 中保持可用。
- `USB-C` 的电源入口和保护细节也属于阶段 4 的补充范围，需要与接口资料一起确认。

## RGMII 收口

1. 角色
- `U5 RTL8211F` 负责千兆以太网 PHY。
- `U2` 负责 RGMII 主机侧信号。
- `J6` 负责外部 RJ45 和磁性器件接口。

2. 必须落实的内容
- PHY 选型和封装。
- MDC/MDIO 管理链路。
- PHY 复位与 PMIC / SoC 的时序关系。
- 磁性器件和板级走线约束。

3. 关键原则
- RGMII 必须跟着成熟参考板的拓扑和长度约束走。
- 不允许把以太网复位或磁性器件放进 boot-critical 逻辑里。
- 布局阶段必须优先保证参考平面和回流路径。
- 在参考捕获完成前，不要把 `U5`、`U6`、`J9` 的外围细节当成最终实现。

## USB 收口

1. 角色
- `U6 USB2514B` 负责 USB2.0 Hub。
- `U2 USB0` 作为 Hub 上游。
- `J7`、`J8` 作为下游 USB Host 端口。

2. 必须落实的内容
- Hub 上游和下游的差分对连接。
- Hub 复位和电源控制。
- 下游端口保护和机械连接器位置。
- 端口供电和板级电源入口的隔离关系。

3. 关键原则
- USB Hub 必须保持在外设扩展域，不得干扰上电和恢复链。
- 下游端口要便于测试和返修。
- 端口供电应当能被明确追踪到板级电源策略。

## HDMI 收口

1. 角色
- `U2` 负责 HDMI 输出信号。
- `J9` 负责外部显示连接。

2. 必须落实的内容
- 连接器封装和机械方向。
- ESD 防护器件。
- 电源和屏蔽相关细节。
- 与显示输出相关的最终布线约束。

3. 关键原则
- HDMI 是外部输出，不应影响 boot-critical 路径。
- 若 V1 只做最小可用 HDMI，也要保留可升级的布局空间。
- HDMI 的连接器与保护器件必须和 SoC 输出通道一起落实。
