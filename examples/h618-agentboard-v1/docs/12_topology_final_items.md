# 拓扑收口最后五项

## 目的

把当前 H618 AgentBoard V1 从“骨架完整”推进到“电气拓扑可定版”的最后五个关键点明确下来。

## 最后五项

1. `U2 H618` 最终器件级 pinmap
- 目标：落实 SoC 的电源、启动、调试和外设引脚归属。
- 原因：这是整板网络命名和后续原理图落图的根基。
- 结果：`UART0 / BOOT0 / FEL / RESET / DDR / RGMII / USB / HDMI` 的 SoC 侧连接不再漂移。

2. `U3 LPDDR4` 完整参考拓扑
- 目标：把 DDR 连接、终端、去耦、参考电压和约束域全部落到参考设计级。
- 原因：DDR 是 H618 板子里风险最高的定版项。
- 结果：在参考设计确认前，只保留骨架级拓扑，不把它误当成完整可布线 DDR 设计。
- 参考资料入口：[`14 DDR 参考设计采集清单`](14_ddr_reference_capture_checklist.md)

3. `U1 PMIC` 最终电源树和时序
- 目标：落实每一条输出、使能信号、上电顺序和保护逻辑。
- 原因：电源树决定整板是否稳定上电，也决定 DDR 和启动链是否能工作。
- 结果：`+3V3 / +1V8 / +1V1_CORE / +1V2_DDR / +0V9_DDR` 的逻辑关系清晰。

4. `MicroSD / SPI NOR / FEL` 恢复闭环
- 目标：确认默认启动、备用启动和恢复入口三条路径都可用。
- 原因：没有恢复闭环，bring-up 阶段的风险会显著上升。
- 结果：调试、恢复和量产前验证路径都能被明确检查。

5. `RGMII / USB / HDMI` 器件级连接
- 目标：落实 PHY、USB Hub、HDMI 连接器及其必要的保护和供电细节。
- 原因：这三类外设会显著影响布线、器件摆位和可用性。
- 结果：这些接口不再只停留在功能位，而是能进入正式原理图实现。
- 参考资料入口：[`15 高速接口参考设计采集清单`](15_high_speed_reference_capture_checklist.md)

## 当前判断

- 前四项属于必须补齐项，其中 DDR 目前仍处于骨架级，不应提前宣布完成。
- 第五项可以在不影响主启动链路的前提下继续细化，但不能长期悬空。
- 这五项补齐后，才比较有把握称为“电气拓扑完整”。

## 建议顺序

1. 先补 `U1 PMIC`。
2. 再补 `U3 LPDDR4`。
3. 同步落实 `U2 H618` pinmap。
4. 收口 `MicroSD / SPI NOR / FEL`。
5. 最后细化 `RGMII / USB / HDMI`。
