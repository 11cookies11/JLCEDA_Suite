# 高速接口参考设计采集清单

## 目的

把 `RGMII / USB Hub / HDMI / USB-C` 这些高速和外设接口从“当前有连接”推进到“可以按参考设计继续扩展”的状态。

## 采集原则

1. 先采器件与封装，再采 pinmap。
2. 先采电源与去耦，再采信号细节。
3. 先采约束，再扩展拓扑。
4. 不把未验证的接口画成“已经完全定版”的样子。

## 需要采集的内容

### 1. RGMII

- PHY 型号和封装。
- Strap 脚默认状态。
- Reset 时序和上电顺序。
- MDC / MDIO 上拉与总线电压。
- TX / RX clock delay 模式。
- 磁性器件侧参考连接方式。
- 是否需要额外终端或串阻。

### 2. USB Hub

- Hub 型号和配置脚。
- Reset 默认状态。
- 上游 / 下游供电路径。
- 下游端口限流和保护策略。
- ESD 放置位置。
- 是否需要晶振、参考电源或额外 strap。

### 3. HDMI

- 连接器型号和真实脚位。
- DDC、HPD、5V 检测与默认状态。
- ESD 器件位置。
- 差分对连接关系和屏蔽策略。
- 是否需要额外的电平保护或电源检测。

### 4. USB-C

- VBUS 保护和浪涌策略。
- 输入 TVS 的放置原则。
- CC1 / CC2 的 sink 默认状态是否继续保持。
- 机械壳地和系统地的连接策略。
- 是否要补数据口 ESD 或更完整的接口保护。

## 采集顺序

1. 器件与封装。
2. pinmap 和 strap。
3. 电源 / 去耦。
4. 版图约束。

## 完成标准

- 每个接口都有可引用的参考资料。
- 每个接口的默认状态和保护策略都能写回模型。
- 采集完成后，才把接口从“参考捕获中”推进到“拓扑扩展中”。
