# H618 AgentBoard V1 PCB 布局计划

Status: Draft

## 目标

- 把当前已经收口的原理图拓扑，转成可执行的 PCB 摆位与布线计划。
- 第一版优先保证可布线、可测量、可返修，而不是追求极限紧凑。
- 让后续的 PCB 绘制、DRC 收敛、样板调试都基于同一份约束说明。

## 当前输入基线

- 原理图工作区已同步到源码目录。
- H618、PMIC、LPDDR4、SPI NOR、MicroSD、Ethernet PHY、USB Hub、USB Host、Micro HDMI、调试口与扩展口都已进入统一的 EasyEDA/JLC 资源链。
- 现阶段的初版工作区已经可以作为 PCB 摆位的起点。

## 布局优先级

1. `U2` SoC
2. `U1` PMIC
3. `U3` LPDDR4
4. `U5` Ethernet PHY
5. `U6` USB Hub
6. `U4` SPI NOR
7. `J2` MicroSD
8. `J1` 电源输入
9. `J3` 调试串口
10. `J4` 扩展口
11. `J6` RJ45
12. `J7 / J8` USB Host
13. `J9` Micro HDMI

## 推荐摆位策略

- `U2 / U3 / U1` 保持在板中心或中心偏上区域，优先保证 DDR 和电源回路最短。
- `U5` 靠近 `J6`，缩短 RGMII、磁性器件和 RJ45 的相关路径。
- `U6` 靠近 USB Host 端口，减少下游供电与数据走线长度。
- `J2`、`U4`、`J3` 放在 SoC 可访问区域，保证启动、恢复和调试流程不被其他大件遮挡。
- `J1` 单独放在板边，尽量远离高噪声回路。
- `J9`、`J7`、`J8`、`J4`、`J5`、测试点统一按边缘可触达原则排布。

## 关键约束

### DDR

- `U3` 必须紧贴 `U2`。
- DDR 走线区域不得被其他模块切断。
- 参考平面、去耦和回流路径优先级高于局部紧凑。

### 电源

- `J1 -> F1 / D1 / U1` 的路径要短、直、清晰。
- PMIC 输出到 SoC 和 DDR 的供电网络要避免长距离绕行。
- 关键电源点位必须预留测试点。

### 高频接口

- `RGMII / USB / HDMI / DDR` 必须优先布线。
- 这些网络之间保持连续参考平面，避免跨分割。
- 高速线附近不要放开关电源噪声源。

### 调试与恢复

- `J3`、`RESET`、`FEL`、`BOOT` 必须在板外可操作、可探测。
- 首版样机需要保留返修空间和飞线窗口。

## 推荐布线顺序

1. 电源与地回路
2. DDR
3. 时钟
4. RGMII
5. USB
6. 启动存储
7. 调试与测试点
8. 其余连接器与丝印

## 产出物

- PCB 摆位草图
- 板框与接口定位说明
- 关键网络的布线优先级表
- DRC / 返修关注点清单

## 需要继续确认的事项

- 最终板框尺寸
- PCB 层数与叠层方案
- 连接器的边缘分布方式
- 是否需要预留散热片或屏蔽件空间
