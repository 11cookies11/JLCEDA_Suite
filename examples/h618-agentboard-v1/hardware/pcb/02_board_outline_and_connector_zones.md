# H618 AgentBoard V1 板框与连接器分区

Status: Draft

## 目标

- 把板框、连接器、调试口和核心器件区域划分清楚。
- 让后续摆位和布线先满足可制造、可插拔、可调试，再考虑外观和紧凑度。

## 板框原则

- 板框优先采用规整外形，避免不必要的凹凸边。
- 所有板边连接器都要提前预留插拔空间和壳体空间。
- 芯片区与边缘连接器之间保留明确的布线通道。

## 区域划分建议

### 1. 核心计算区

- 放置 `U2 / U3 / U1`
- 该区域以 DDR 和电源路径为中心
- 不能被大尺寸连接器或高件遮挡

### 2. 启动与恢复区

- 放置 `J2 / U4 / J3 / RESET / FEL / BOOT`
- 该区域必须便于人工触达
- 首版样机应允许飞线、探针和返修

### 3. 网络与外设区

- 放置 `U5 / J6`
- 尽量缩短 PHY 到 RJ45 的关键路径

### 4. USB 区

- 放置 `U6 / J7 / J8 / J1`
- 供电口与 Host 口需要物理隔离，避免误插和干扰

### 5. 显示与扩展区

- 放置 `J9 / J4 / J5`
- 扩展口优先保证可接线和可标识

## 连接器边缘规则

- 调试口、USB、RJ45、MicroSD、Micro HDMI、扩展口应尽量靠边。
- 同一边缘上的接口要避免机械冲突。
- 高速接口的外部保护器件应尽量靠近接口引脚。

## 机械与可维护性

- 关键测试点不得被大器件遮挡。
- 按键和跳线开关要在装配后仍然可操作。
- 板上最热区域要保留散热路径和必要间距。
