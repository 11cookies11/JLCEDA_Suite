# JLCEDA Suite Decision Log Template

This reference defines the minimal decision record the agent should keep while synthesizing or refining a circuit.

## Goal

Make the design reasoning traceable.

Use this reference when:

- a component or strap choice is made
- a topology choice is locked in
- a parameter is computed or assumed
- a simulation outcome changes the design

## Record fields

For each meaningful decision, record:

- decision topic
- chosen option
- why it was chosen
- supporting source or calculation
- risk if the choice is wrong
- whether user confirmation is still needed

## Good practice

- keep each decision short and explicit
- separate facts from assumptions
- keep the assumption visible in later outputs
- reuse the same record in later revisions

## Suggested usage

The agent should place the decision log into:

- requirement clarification summaries
- SCD notes
- circuit model risks
- simulation follow-up summaries
